# Steam Game Value Finder

My app helps gamers decide which games to buy by comparing different prices, the gameplay, and ratings..

> A course project for **MIST 4600: Computer Programming in Business** at the University of Georgia's Terry College of Business (Fall 2026).

## Problem
The problem is gamers have so many different games to choose from. This can make the buyers feel uncomfortable or even overwhelmed when trying to decide between games. My app takes games and puts them into categories to best fit what you need. Then you make your buying decision then.
## What it does
My app answers three questions:
1. **Sub-question 1:** Which highly rated games fit the gamer’s budget and preferred genre?
2. **Sub-question 2:** Which games offer the most gameplay per dollar?
3. **Sub-question 3:** Which games have the best combination of affordable prices and best reviews?

## Data
The [Steam Games Dataset](https://www.kaggle.com/datasets/artermiloff/steam-games-dataset) on Kaggle, collected in March 2025. The dataset is shared under the MIT License by its creator, artermiloff. This repo uses `steam_games.csv`, a smaller file made for the course: the 1,000 games with the most reviews.
